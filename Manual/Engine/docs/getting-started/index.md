# 阅读与查询说明书

- 功能状态：已实现（说明书能力）
- 适用对象：所有用户

## 分类浏览

左侧导航按使用场景分组。概念页回答“是什么”，命令页回答“怎么写”，示例页提供完整脚本，排错页解释失败原因。

## 中文搜索

搜索索引使用中文分词，并额外收录 LyoCrystal 专有名词。可以搜索：

```text
小数变量
私人持久
热重载
P0
character_script_variables
server_script_variables
Server.Variables.json
DeclarationConflict
```

如果某个常用词无法找到正确页面，应将它加入项目搜索词典，并在对应页面补充正式术语或别名。

## 离线阅读

离线发布物是完整静态站点目录。为保证全文搜索正常，建议由本地或内网 HTTP 服务打开，不直接双击零散 HTML 文件。
