# 当前目标与跨角色变量

- 功能状态：实验性（VAR-07 实现完成）
- 首次支持版本：开发版 2026-08-15
- 适用范围：在线角色；服务端主线程

跨角色变量用于读取当前目标，或在两个在线角色之间显式传递变量。它不会打开离线角色存档，也不会绕过变量原有的类型、作用域和保存规则。

## 设置当前目标

```text
MOV S$目标名称 张三
SETCURRTARGET S$目标名称
```

目标必须同时满足：

1. 当前在线；
2. 与执行者位于同一地图实例；
3. 距离不超过 20 格。

传入空参数可清除当前目标。角色小退或掉线时，当前目标也会自动清除。

## 读取当前目标

`C.` 是只读视图，只支持以下形式：

```text
<$C.STR(U10)>
<$C.HUMAN(KillCount)>
<$C.GUILD(WarScore)>
```

`C.STR(reference)` 读取目标角色可访问的普通变量；`C.HUMAN(name)` 和 `C.GUILD(name)` 分别读取目标的角色、行会自定义变量。每次读取都会重新检查目标是否在线、同图且在 20 格内；目标失效时显示为空，不会继续使用旧对象。

不能对 `C.` 执行 `MOV/INC/DEC`。需要修改目标时必须使用 `SETHUMVAR`，这样错误、类型检查和自动保存都会经过统一变量模块。

## 写入在线角色变量

```text
SETHUMVAR 张三 HUMAN.EventScore 10
SETHUMVAR S$目标名称 U.DropRate P.RewardRate
```

命令格式：

```text
SETHUMVAR 目标角色名 目标变量 值或自己的变量
```

目标必须在线。目标变量仍受原作用域约束：例如 `HUMAN`、`U` 写入目标角色的持久数据，成功后进入现有自动保存；`N` 写入目标的在线临时数据。不能把调用者的私人上下文冒充成目标上下文。

## 读取在线角色变量

```text
GETHUMVAR 张三 HUMAN.EventScore P0
GETHUMVAR S$目标名称 U.DropRate P.Result
```

命令格式：

```text
GETHUMVAR 目标角色名 来源变量 自己的目标变量
```

读取发生在目标角色上下文，写回发生在调用者上下文。来源和目标都执行正常的声明、类型及作用域检查；任何一步失败时，目标变量保持旧值。

## 限制与安全边界

- 第一版只允许在线角色，不提供离线写档。
- 角色名来自变量时只解析调用者自己的普通变量，不执行任意表达式。
- `C.` 永远只读；跨角色修改必须是显式命令。
- 命令必须在服务端主线程执行。
- 持久变量的保存策略没有变化，仍由当前 Provider 和自动保存管理。

失败时服务端日志使用 `[Variables][TXT]` 前缀。目标离线会报告 `TargetOffline`；当前目标不存在、跨图或超距会报告 `SETCURRTARGET` 失败。
