# 作用域与生命周期

- 功能状态：部分实现（P/D/M/N/S/I/Call/U/T/G/A/J/Z/HUMAN/GUILD/GLOBAL 为实验性）
- 首次支持版本：开发版 2026-08-15

| 作用域 | 编号变量 | 所有者 | 清除或保存时机 | 是否持久 |
|---|---|---|---|---|
| `P` | `P0-P999` | 当前人物 + 当前 NPC 对话 | 关闭或切换 NPC | 否 |
| `D` | `D0-D999` | 当前人物连接 | 断线 | 否 |
| `M` | `M0-M999` | 当前人物地图停留 | 换图 | 否 |
| `N` | `N0-N999` | 当前人物在线会话 | 小退/断线 | 否 |
| `S` | `S0-S999` | 当前人物在线字符串 | 小退/断线 | 否 |
| `I` | `I0-I999` | 当前服务器进程 | 服务器重启 | 否 |
| `Call` | 仅命名变量 | 单次 C# NPC 调用帧 | 回调返回且调用帧释放 | 否 |
| `G` | `G0-G999` | 全服 | 自动保存 | 是 |
| `A` | `A0-A999` | 全服字符串 | 自动保存 | 是 |
| `U` | `U0-U499` | 单个人物 | 自动保存 | 是 |
| `T` | `T0-T499` | 单个人物字符串 | 自动保存 | 是 |
| `J` | `J0-J499` | 单个人物 | 每日周期清零 | 是 |
| `Z` | `Z0-Z499` | 单个人物字符串 | 每日周期清零 | 是 |

当前命名小数变量支持 `P/D/M/N/I/U/G/J/HUMAN/GUILD/GLOBAL/Call`。字符串作用域不直接进行小数运算。

!!! warning "当前版本范围"
    当前开发版开放 P/D/M/N/S/I/Call/U/T/G/A/J/Z/HUMAN/GUILD/GLOBAL；复合值、公式、跨对象访问仍是后续目标。

## 全局持久作用域

- `G0-G999`：全服持久整数；`G.名称` 可声明为 `Integer` 或 `Decimal`。
- `A0-A999`：全服持久字符串；`A.名称` 声明为 `String`。

所有人物、NPC 与 C# 脚本读取的是同一份 G/A 状态。成功修改后请求服务器变量自动保存；关闭 NPC、换图、人物掉线、脚本热重载和服务端正常重启均不清除。原始 NPC `A*` 临时槽位已取消，`A0` 从本版本起直接表示当前全局持久字符串。

详见[全局持久变量与数据库](global-persistence.md)。

## 每日与自定义作用域

- J/Z：归单个角色，每个运营日周期自动清除，详见[每日周期变量](daily-variables.md)。
- HUMAN：归单个角色的命名永久数值。
- GUILD：归行会的命名永久数值，同一行会成员共享。
- GLOBAL：归当前服务器的命名永久数值，全服共享。

HUMAN/GUILD/GLOBAL 不支持固定编号，必须先声明后使用，详见[自定义持久作用域](custom-scopes.md)。

## 私人持久作用域

- `U0-U499`：人物私人持久整数，适合次数、开关和累计数值。
- `T0-T499`：人物私人持久字符串，适合称号、阶段名和外部标识。
- `U.名称`：先由 C# 启动脚本声明，可选择 `Integer` 或 `Decimal`，适合命名小数。
- `T.名称`：先声明为 `String`，适合可读的私人持久文本。

U/T 值归属于角色本身，关闭 NPC、换图、小退、掉线及正常服务端重启均不清除。角色归档和恢复也会携带这些值。固定编号只允许 `0-499`；超出范围会失败，不会改写其他变量。

详见[私人持久变量与数据库](persistence.md)。

## P 的清除边界

- 同一人物、同一 NPC 对话翻页：保留。
- 切换到另一个 NPC：首次访问新对话时清除旧 P 数据。
- 点击关闭、`@Exit` 或关闭全部窗口：客户端通知服务端清除。
- 小退、断线或连接销毁：服务端主动清除。
- 客户端重复发送或发送旧 NPC 的关闭通知：服务端按对象号拒绝，不影响新对话。

## 运行时作用域的清除边界

- `D`：同一人物连接内跨 NPC、跨地图保留；`PlayerObject.StopGame` 时清除。
- `M`：同一地图实例内保留；地图实例对象变化后首次访问立即清除，掉线也清除。
- `N` 与 `S`：同一人物在线期间保留；小退、掉线或连接销毁时清除。
- `I`：所有人物共享；脚本热重载保留，服务端 `Envir` 停止或进程结束时清除。
- `Call`：以 `NpcPageCall` 为所有者；嵌套调用互不覆盖，调用帧释放后不可再访问。

`N$名称` 是免声明的在线整数扩展变量，`S$名称` 是免声明的在线字符串扩展变量：

```text
MOV N$击杀计数 10
INC N$击杀计数 1
MOV S$任务阶段 已完成
```

在线命名变量需要 Decimal 时必须显式注册，例如 `N.DropRate`。它与 `N$击杀计数` 生命周期相同，但类型由声明固定。

## 选择建议

- 只在当前 NPC 页面使用：`P`。
- 登录期间跨 NPC 使用：`N` 或 `D`，根据是否区分完整连接选择。
- 换图必须失效：`M`。
- 人物重登后仍保留：`U` 或 `HUMAN`。
- 每天重新计算：`J`。
- 全服共同读取且重启保留：`G` 或 `GLOBAL`。
- 行会共同读取：`GUILD`。

错误选择作用域会造成数据提前清除、长期残留或人物之间意外共享。
