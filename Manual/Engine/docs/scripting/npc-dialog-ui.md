# NPC 对话、按钮与客户端

- 兼容等级：B（基础文本与按钮）
- 适用入口：普通 NPC `#SAY`
- 最后复核：LFM2-2026-08-15-snapshot

## 基础对话

```text
[@MAIN]
#SAY
欢迎来到比奇省。\
<领取奖励/@REWARD>\
<关闭/@Exit>
```

TXT 文本先执行现有占位符替换，再以 `NPCResponse` 的字符串列表发送。中文、内联按钮和页面标签不新增协议字段。`@Exit` 由客户端按既有关闭语义处理。

## 页面安全

`<文字/@页面>` 中的页面标签会进入当前页面允许跳转集合。客户端点击时，服务端仍校验 NPC 对象、脚本 ID、当前页以及该按钮是否真实出现在成功分支；脚本不能借自定义按钮跳到未授权页面。`GOTO` 等服务端即时跳转另受 `TxtScriptsMaxImmediateTransitions` 限制。

## 客户端范围

- PC 客户端继续使用既有 NPC 对话控件和共享 `NPCResponse` 包。
- MonoGame 共享客户端把内联按钮解析为 FairyGUI 选项，并在缺少绑定资源时使用现有移动端 NPC 兜底窗口。
- 本阶段没有修改 `src/Shared/Shared/Packet.cs`，也没有新增包 ID；协议往返测试证明中文行和按钮语法保持一致。

PC 与 MonoGame/Android 编译均属于发布门禁。Android x64 已在 API 36.1 后台模拟设备完成真实安装、自动注册测试账号、创建角色、进入游戏，并实际打开世界中的 `TXT灰度向导_验证`。`[@MAIN]` 的中文、换行和内联按钮正常，点击后进入 `[@VERIFY]` 并完成地图、怪物计数与会话变量闭环；设备截图和运行时分派证据保存在 `Docs/Evidence/TXT-12-20260815`。客户端截图来自可复现的后台模拟设备运行，不是设计示意图。
