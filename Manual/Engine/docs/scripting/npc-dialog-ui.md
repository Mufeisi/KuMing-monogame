# NPC 对话、按钮与客户端

- 兼容等级：B（基础文本与按钮）
- 适用入口：普通 NPC `#SAY`
- 最后复核：LFM2-2026-08-15-snapshot

## 基础对话

```text
[@MAIN]
#SAY
欢迎来到比奇省。\
<领取奖励/@REWARD>\
<关闭/@Exit>
```

TXT 文本先执行现有占位符替换，再以 `NPCResponse` 的字符串列表发送。中文、内联按钮和页面标签不新增协议字段。`@Exit` 由客户端按既有关闭语义处理。

## 页面安全

`<文字/@页面>` 中的页面标签会进入当前页面允许跳转集合。客户端点击时，服务端仍校验 NPC 对象、脚本 ID、当前页以及该按钮是否真实出现在成功分支；脚本不能借自定义按钮跳到未授权页面。`GOTO` 等服务端即时跳转另受 `TxtScriptsMaxImmediateTransitions` 限制。

## 客户端范围

- PC 客户端继续使用既有 NPC 对话控件和共享 `NPCResponse` 包。
- MonoGame 共享客户端把内联按钮解析为 FairyGUI 选项，并在缺少绑定资源时使用现有移动端 NPC 兜底窗口。
- 本阶段没有修改 `src/Shared/Shared/Packet.cs`，也没有新增包 ID；协议往返测试证明中文行和按钮语法保持一致。

PC 与 MonoGame/Android 编译均属于发布门禁。Android x64 已在 API 36.1 后台模拟设备完成真实安装、自动注册测试账号、创建角色、进入游戏，并实际打开世界中的 `TXT灰度向导_验证`。`[@MAIN]` 的中文、换行和内联按钮正常，点击后进入 `[@VERIFY]` 并完成地图、怪物计数与会话变量闭环；设备截图和运行时分派证据保存在 `Docs/Evidence/TXT-12-20260815`。客户端截图来自可复现的后台模拟设备运行，不是设计示意图。

## NPC 大对话框

```text
#ACT
OPENMERCHANTBIGDLG 1 653 1 4 0 -65 1 480 0 1
```

参数依次为 `EffectImageList.txt` 中的资源序号、图片序号、是否可移动、显示位置、X/Y 微调、是否显示关闭按钮、关闭按钮 X/Y 和是否在当前 NPC 后续页面延续。显示位置 `0..4` 分别为左上、右上、左下、右下和居中。

服务端只从已发布的 `EffectImageList.txt` 解析安全文件名，不接受脚本直接指定宿主任意路径。PC 客户端存在同名 `.Lib` 时使用指定背景；资源缺失时保留所有 NPC 文字和按钮，并回落到标准 NPC 背景。MonoGame/Android 当前使用可操作的标准 FairyGUI NPC 窗口，不渲染原翎风 WIL/Pak 背景，因此本命令兼容等级为 C；要完成原画面 E2 验证，仍需提供并登记对应客户端资源。

```text
#ACT
CLOSEMERCHANTBIGDLG
```

关闭命令结束当前 NPC 会话、清除客户端大对话框样式并恢复标准背景。`CLOSEBIGDIALOGBOX` 作为旧专用登录器别名执行相同关闭动作。

## 仍未兼容的高级界面

任意客户端窗口、标题/滚动消息、商铺和尚未接入的自定义按钮仍按清单保持 D 或 E。只有对应资源、坐标、点击回调、协议兼容和客户端截图全部验证后才允许升级。
