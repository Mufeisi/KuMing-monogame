# 2026-08-15 变量系统 VAR-04

本阶段加入服务器全局持久变量：

- `G0-G999` 全服持久整数；
- `A0-A999` 全服持久字符串；
- 已声明的 `G.名称` 支持 `Integer` 与精确 `Decimal`；
- 已声明的 `A.名称` 支持字符串；
- Legacy 使用原子 JSON 主文件和 `.bak` 恢复；
- SQLite/MySQL 使用 `server_script_variables` 表；
- 成功写入触发服务器变量自动保存请求；
- 多人物即时共享，人物掉线、脚本热更和正常服务端重启后保留。

## 不兼容变更

按项目决定，原始 NPC `A*` 临时变量通道已删除。`MOV A0 ...` 现在与其他统一变量命令一样写入全服持久 A 作用域，不再写人物对象的 `NPCVar`。升级前必须搜索现有脚本中的 A0-A999；原来依赖“每个人物/NPC 对话各自一份”的脚本应改用 P、N 或 S，确需全服共享的脚本无需修改。

SQLite/MySQL 首次启动会由第 19 号 SchemaMigration 创建 `server_script_variables`。Legacy 发布时应把 `Server.Variables.json` 和 `Server.Variables.json.bak` 纳入服务端数据备份，不要在更新程序中覆盖。

完整用法见[全局持久变量与数据库](../scripting/variables/global-persistence.md)。

验证基线：55 项变量、生命周期及持久化定向测试通过；正式无界面服务端进程冒烟需报告 `SERVER_PERSISTENCE=True` 后收口。
