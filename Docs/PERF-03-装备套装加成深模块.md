# PERF-03 装备套装加成深模块

## 目标

`Server/MirObjects/HumanObject.cs` 原本同时承担装备扫描、普通套装规则、圣龙戒指组合和天龙部位组合。PERF-03 将其中纯进程内、无 I/O 的套装加成规则提取为 `EquipmentSetBonusModule`，不改变数值、执行顺序或玩家主线程写入边界。

## 模块接口

- `ApplyItemSetBonuses`：接收当前 `Stats`、套装聚合和装备槽快照，隐藏普通套装、局部部位、完整套装与圣龙双戒组合规则。
- `ApplyMirSetBonuses`：接收当前 `Stats` 与已装备天龙部位，隐藏四层可累积组合规则。

模块是 internal 纯内存实现，没有新增端口或适配器。`HumanObject.RefreshStats` 只在原调用顺序中调用这两个接口；原 267 行规则从巨型类移除，而不是复制、`partial` 拆文件或增加转发层。

## 行为保持

- 破碎套装“戒指 + 手镯”分支继续保持原有提前结束语义。
- 圣龙“双花 + 双绿”继续不区分左右手，并在命中后提前结束普通套装处理。
- 神龙局部部位与完整套装加成继续累积。
- 天龙武器防具、头靴腰、首饰和完整八部位四层规则继续按原顺序累积。
- 不修改 `Stats`、`ItemSets`、`UserItem`、协议或装备数据结构。
