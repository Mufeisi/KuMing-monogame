# LEG-10：候选与平行路径关闭记录

- 状态：已接受
- 复核日期：2026-08-14
- 上位门禁：[`LEG-10-统一作者工作台与路线关闭.md`](LEG-10-统一作者工作台与路线关闭.md)
- 事实职责：记录本路线终审时未激活候选和平行实现的保留或关闭决定

## 1. 合服候选

结论：关闭，不立项，不实现合服工具。

原因：当前没有“至少两个真实运营区”的受控证据；账号、角色、公会、排行榜和经济资产冲突模型尚未形成被接受的领域决定；没有脱敏合并演练需求或临时数据库回滚演练。三个准入条件均未满足。未来若业务状态改变，必须另立高风险 PRD，先做只读扫描、冲突报告和临时库演练，不能从本任务直接续做生产合并。

## 2. 玩法与体验候选

| 候选 | 决定 | 重新打开条件 |
|---|---|---|
| 镶嵌组合与补完 | 保留为审计候选 | 三端运行证据证明存在已定义且可复现缺口 |
| 最小称号系统 | 保留，未激活 | 用户以独立 PRD/Issue 批准协议、Schema 和双端显示范围 |
| 账户安全模式 | 保留，未激活 | 完成威胁模型并以独立安全 PRD 激活 |
| 邮件货到付款 | 保留，未激活 | 独立经济事务 PRD 证明零复制、零丢失、零重复扣款门禁 |
| 实例地图产品化 | 保留为能力探针 | 先证明现有多实例在重连、重启、归属和清理上的行为 |
| 玩家拾取过滤、背包整理、一键换装 | 保留，未激活 | 分别明确服务端权威规则和 PC/Android 产品入口 |
| 摆摊、国家/阵营、内功/心法/经脉 | 关闭近期候选 | 有明确玩家体验、经济、内容和平衡目标后重新立项 |
| Buff 子系统重构 | 关闭 | 只有可复现生命周期缺陷可重新打开，不因旧源码结构重构 |
| 离线挂机、旧密码锁、旧关系库、远程日志引擎、巨型全局配置 | 永久排除于本路线 | 不重新打开；若出现全新业务目标，必须按现代架构独立论证 |

这些决定不实现候选，也不把候选设计变成活动队列；后续只有用户明确立项才能进入代码变更。

|---|---|---|
| 协议序列化 | `src/Shared/Shared/Packet.cs` 与协议清单 | 保留唯一实现；未发现本路线新增第二套协议栈 |

| 发布 | `ProjectReleasePublisher`、`TestResourceReleasePublisher` 与签名清单 | 保留唯一实现；工作台审查记录不是发布源 |

| 服务实例 | `Launcher.InstanceManagement` | 新增唯一实例档案/运行事实源；工作台不复制状态 |

本次没有可安全删除的生产平行路径。删除条件要求等价行为回归，而现状复核未发现由 LEG-09/LEG-10 新实现明确取代且可独立删除的旧入口；因此“无删除”是边界决定，不以静态“未使用”推断删除资源或代码。
