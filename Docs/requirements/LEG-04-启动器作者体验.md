## 1. 任务简报

- 目标：在现有 `Launcher.Editor` 中完成可视化启动器皮肤编辑、四档 DPI 预检和真实玩家入口生成闭环。
- 用户价值：运营人员不手写 JSON 或坐标，即可选择控件、调整布局与样式、保存项目并生成可运行玩家入口。
- 做：运行时坐标映射、控件树、单选/多选、移动/缩放、对齐/分布、层级、锁定/隐藏、属性与四态资源、撤销/重做、未保存提示、DPI 预检、真实生成与离线冒烟。
- 不做：通用 GUI 框架、自定义游戏 GUI、微端发行体验重构、新协议或第二套渲染运行时。
- 方法约束：复用现有 `Launcher.ThemeRuntime` 渲染和玩家壳生成接缝；玩家快照保持向后兼容，编辑器专属状态只进入项目文件。
- 风险等级：中，涉及编辑器状态、主题快照和玩家入口生成。
- 完成定义：`GATE-UXL` 七项能力可操作、可保存、可撤销；四档 DPI 预检通过；当前源码生成的真实玩家入口可启动并显示所选区服与公告；既有签名发布、历史和回滚回归通过。
- 语言：任务交流、文档、状态和提交信息均使用中文。

## 2. 设计与兼容边界

1. 画布初始坐标由实际 `LauncherForm` 控件边界反向提取，保存后仍由同一运行时正向渲染，避免编辑器维护第二份布局算法。
2. 控件层级沿用 `LauncherTheme.Controls` 列表顺序；玩家快照不新增 `Locked` 或 `ZIndex` 字段，旧玩家运行时仍可读取新快照。
3. 锁定状态属于作者体验元数据，保存在 `EditorProject.CanvasControls`，不进入玩家发布快照。
4. 编辑历史覆盖增加、删除、移动、缩放、属性、显示、锁定和层级；保存建立新的脏状态基线。
5. 资源编辑沿用现有项目 `Assets` 管理和预检，不复制参考源码皮肤、图片或坐标。

## 3. 退出门禁

1. 空白或模板项目可直接进入画布，背景、按钮、公告、区服列表可视化编辑，无须手写 JSON 或坐标。
2. 控件树、单选、多选、移动、缩放、层级、吸附、对齐、等距分布、锁定和隐藏均可用。
3. 前景、背景、字体、字号、粗体、透明度和控件背景资源可编辑；启动按钮常态、悬停、按下、禁用四态有集中入口。
4. 增删、移动、缩放、属性、锁定和层级修改支持撤销/重做；切换项目或关闭时对未保存修改给出保存提示。
5. 100%、125%、150%、200% 四档预检均能渲染并保留问题定位工件。
6. 当前源码玩家壳和客户端负载生成真实入口；入口启动后主窗口标题、区服与公告来自项目快照。
7. 既有签名发布、不可变历史、离线包、密钥恢复和回滚测试无回归。

## 4. 独立实现与许可边界

- 本任务只吸收参考项目中的控件树、画布操作和属性编辑工作流，未复制 Delphi 代码、资源、协议常量或皮肤。
- 实现完全基于本仓库现有 C# WinForms、主题运行时、签名发布和玩家壳接缝。
- 参考源码许可证未被重新认定；任何来源不明的实现和素材均未进入提交或发布物。

## 5. 回滚

本任务不改数据库和网络协议。回滚本任务提交即可恢复原表格坐标编辑入口；已有项目的玩家快照仍保持原格式，新增 `CanvasControls` 仅为编辑器可忽略字段。完成证据见 [`../Evidence/LEG-04-20260813/README.md`](../Evidence/LEG-04-20260813/README.md)。
