## 1. 任务简报

- 目标：把登录、移动、攻击、施法、拾取、聊天和超大封包纳入可观察、可测试、可关闭的服务端权威行为治理。
- 用户价值：正常玩家不被模糊阈值误伤；异常会话具有可检索证据，运维可先观察基线，再受控启用或回退软限制。
- 做：七类统计、观察/执行/关闭模式、五级响应、结构化证据、受控管理接口、主线程处置、性能对比。
- 不做：硬件封禁、自动永久封号、旧网关移植、新协议、第二个网络宿主或客户端状态权威。
- 方法约束：复用现有 `MirConnection` 主循环、SEC-04 管理鉴权、原子配置和服务日志；生产配置损坏时拒绝启动网络监听。
- 风险等级：高，涉及网络输入、安全默认值、运行配置和玩家会话处置。
- 预估成本：3～6 人周；本次以一条完整纵向闭环为阶段工件，不扩建 UI。
- 完成定义：正常链路零误杀；七类流量可查询；超频和超大封包可识别；执行模式能按规则丢弃或断开；配置可关闭、原子回退且代次受保护；同环境性能开销满足本规格阈值。
- 验证：领域测试、管理 HTTP 集成测试、真实 TCP 超大帧/主线程断开测试、当前源码正常协议负载、同进程性能对比、受影响构建及全量回归。
- 回滚：管理端先切换 `Disabled`；代码回滚本任务提交。配置格式不改数据库或协议，无数据迁移。

## 2. 安全与线程边界

1. 网络回调只解析现有协议并识别声明帧长；不得直接写玩家、账户或世界状态。
2. 动作分类、丢弃、短期限制、断开和人工复核标记均在 `MirConnection.Process` 所在服务端主循环作出。
3. 无效封包继续沿用失败关闭保护；超大但格式可判定的封包进入本阶段结构化证据。
   对只发送协议头而不发送完整正文的超大帧，服务端保证快速移除会话和保留证据；由于 Windows 可能对未读正文连接发送 TCP RST，不承诺客户端一定收到应用层断开原因包。
4. 审计只保存会话号和来源地址的稳定散列引用，不记录 IP 明文、凭据或聊天正文。
5. 只有 Administrator 可改策略；Operator 可查询。写入要求完整策略和匹配代次，先原子落盘再发布不可变快照。

## 2.1 独立实现与许可边界

- 参考项目许可边界未在本任务中被重新认定，因此任何来源不明的代码或资源均不进入提交；后续若要引入具体实现，必须另行完成来源和许可证审核。

## 3. 首批行为

| 类别 | 协议动作 | 默认模式与响应 |
|---|---|---|
| 登录 | 版本、注册、改密、登录、角色、开始游戏 | Observe；超阈值警告 |
| 移动 | 转向、步行、跑动 | Observe；候选丢弃单次动作 |
| 攻击 | 普攻、范围攻击、采集攻击 | Observe；候选丢弃单次动作 |
| 施法 | 技能键、施法、技能开关 | Observe；候选丢弃单次动作 |
| 拾取 | 拾取 | Observe；候选丢弃单次动作 |
| 聊天 | 聊天 | Observe；候选短期限制 |
| 超大封包 | 声明帧长超过策略上限 | Observe；候选断开 |

响应模型固定为警告、丢弃单次动作、短期限制、断开、人工封禁复核。`Observe` 只计数和记录，不执行处罚；`Enforce` 执行策略；`Disabled` 不计数、不判定，是运行时 Kill Switch。

## 4. 运维入口

- 查询：`GET /operations/gateway-governance`
- 修改：`POST /operations/gateway-governance/set`
- 持久化：`Configs/Operations/gateway-governance.json`

接口沿用 SEC-04 的可信来源与 Bearer 角色鉴权。修改正文必须包含 `expectedRevision`、`mode`、`maximumPacketBytes`、完整 `rules` 和不少于 3 个字符的 `reason`。

## 5. 退出门禁

1. 每类动作至少有一个映射测试，正常阈值内流量无处置。
2. 超频及超大封包分别产生含规则、阈值、观测值、时间和会话的证据。
3. 观察模式不处罚；执行模式的丢弃、短期限制、断开和人工复核语义可验证；关闭模式零计数零处罚。
4. 配置缺字段、未知版本、非法阈值均失败关闭；并发旧代次不能覆盖新配置。
5. Operator 只能查询，Administrator 才能修改；审计不泄露来源地址明文或正文。
6. 玩家动作处置发生在服务端主循环；网络回调不直接写玩家状态。
7. 同环境每次分类判定的中位绝对增量不超过 5 微秒；关闭模式保持无锁快速返回。
8. 当前源码正常协议负载通过，受影响构建通过；完整 `Base05.Tests` 不得出现可复现的本任务回归。
