- 分支：`codex/leg-07-gui-protocol`
- 语言：中文

## 交付工件

1. Shared 新增客户端动作包 `CustomGuiAction`，以及服务端打开、状态增量、动作结果、关闭四类包；包号只追加为客户端 `145`、服务端 `275..278`。
2. 协议统一携带窗口实例、GUI 文档/修订、签名包序列、会话随机数、请求序号和状态修订，为后续服务端会话门卫提供完整身份输入。
3. 编解码器对包体字节数、字符串、集合、列表、物品格和聚合数量实施硬上限；拒绝未知枚举、重复键、非法 UTF-8、尾随数据、截断帧及互相冲突的动作负载。
4. PC、Server 与 Android 正式编译均消费同一 Shared 协议事实源；历史 `wire-v1` 包号与字段保持冻结，新能力登记为只追加的 `gui-wire-v2`。

## TDD 与攻击面

测试先引用尚不存在的 `CustomGuiAction`、服务端生命周期包和编解码类型，得到编译失败；实现后转绿。攻击回归覆盖超长文本、超量选择/物品、聚合集合超限、未知枚举、非法 UTF-8、截断包、尾随字节、重复状态键及互斥负载并存。所有拒绝均在进入后续业务处理前发生，稳定诊断前缀为 `GUI07-PROTOCOL-*`。

## 兼容与回滚

`wire-v1` 的客户端 `0..144`、服务端 `0..274` 保持冻结，旧客户端不会接收未登记的新包。回滚时先停止服务端发送 `gui-wire-v2`，再逆序回滚本切片；不得复用已登记的 `145/275..278` 表达其他语义。协议细节见 [`../../design/custom-gui/游戏GUI动态协议规范.md`](../../design/custom-gui/游戏GUI动态协议规范.md)，兼容基线见 [`../../quality/protocol/PROTO-03-协议与资源兼容矩阵.md`](../../quality/protocol/PROTO-03-协议与资源兼容矩阵.md)。

## 范围说明
