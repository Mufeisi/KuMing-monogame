## 端到端工件

1. 火球术名称与图标经过服务端编辑会话重验后写入真实 `MagicInfo` 二进制，重新构造 `MagicInfo` 后保持修改；其余 17 个战斗字段逐项不变。
2. 重载后的事实对象由现有 `UserMagic.CreateClientMagic()` 生成服务端批准投影，并通过现有 `ClientMagic.Save`/构造函数协议往返；名称、图标、范围、消耗与冷却一致。
3. 保存前后的四级消耗、冷却与伤害结果完全相同；空名称、超长名称、控制字符、并发冲突、取消和持久化失败路径均被覆盖。
4. 隐藏服务器在不绑定网络、不启动脚本和 HTTP 的条件下进入 `Ready`，消费火球术只读、空间、时间与服务端批准投影后正常停止。
