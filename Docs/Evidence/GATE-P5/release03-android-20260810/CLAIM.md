# RELEASE-03 任务简报

- 目标：完成 Android 正式签名、资源更新、生命周期与密钥恢复的开发阶段门禁，交付可安装 APK 与可复验记录。
- 做：修复正式签名索引接线；封住签名整版未集齐时的单包旁路；保护用户运行时配置；四态构建；等效设备安装/升级/下载恢复/生命周期；密钥灾备实跑。
- 不做：不创建数百个实体账号或设备；不重复容量压测；不伪报实体手机来电、蜂窝射频、刘海和手感；不改协议、渲染、脚本或数据库 Schema。
- 方法约束：复用现有 Bootstrap、事务发布、ReleaseSigningTool、正式 Android 宿主与真实协议服务端；秘密不写日志或 Git。
- 预估时间：3～5 小时；单次 AOT 慢外环只在最终修复后重跑。
- 完成定义：代码与专项/全量 TRX、四态构建输出、同签名升级、签名资源整版提交、生命周期命令结果、恢复后正式签名 APK 与证书摘要均有工件。
- 语言：交流、文档、证据与提交信息全部使用中文；命令和代码标识符除外。
