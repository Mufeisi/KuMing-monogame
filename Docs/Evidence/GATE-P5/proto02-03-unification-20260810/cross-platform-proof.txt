目的：复现 Ubuntu checkout 使用 LF 时的协议清单校验。

1. 从提交 8a1ff5b 创建独立临时克隆，设置 core.autocrlf=false、core.eol=lf。
2. 使用换行格式化把临时克隆 Shared 下 C# 文件转换为 LF；不修改正式工作树。
3. git ls-files --eol 输出：
   i/lf    w/lf    attr/text=auto         Shared/ClientPackets.cs
   i/lf    w/lf    attr/text=auto         Shared/Packet.cs
4. 在该 LF 工作树执行 Release 生成器 --verify。

输出：协议清单无漂移：C:\Users\luo\AppData\Local\Temp\lyo-proto-lf-20260810\Docs\protocol-wire-manifest.generated.json
退出码：0。

结论：生成器对源文本先统一 CRLF、LF 和单 CR，再计算 UTF-8 SHA-256；Windows 与 Ubuntu 的换行差异不会造成 CI 误报。
