# GM 启动器与独立微端部署说明

## 1. 你会得到什么

- `LyoCrystal.LauncherEditor.exe`：GM 离线编辑器，自包含运行，不要求安装 .NET、Visual Studio 或 SDK。
- `项目名-玩家入口.exe`：玩家只需下载并运行这一个文件，可重命名，可通过网盘或群文件分发。
- `项目名-微端网关.zip`：部署到独立微端服务器的自包含程序包。
- 离线发布包和密钥恢复包：用于无公网编辑环境的发布与项目恢复。

代码签名、域名和 HTTPS 都不是首版部署门槛。正式生产可以使用 HTTP、服务器 IP 和端口。

## 2. 第一次建立项目

1. 双击编辑器，选择“新建项目”；不熟悉选项时可以跳过向导。
2. 填写项目名称、窗口标题、任务栏名称和玩家 EXE 文件名。
3. 在“默认微端”中填写微端服务器 IP、端口；访问 User 由项目自动生成并同步。
4. 编辑区服地址、端口和运营状态。只有特殊区服需要填写微端覆盖。
5. 选择经典、紧凑下拉或宽屏侧栏模板；侧栏/下拉模式由 GM 固定。
6. 编辑公告和玩家默认分辨率、窗口模式、音量等设置。
7. 执行发布前检查，修正缺图、越界、重叠、文字截断或非法链接后再生成。

仓库自带的 `Docs/Examples/launcher-editor-sample` 可复制到编辑器工作区作为起点。示例地址仅用于说明，必须替换为实际游戏服和微端服务器地址。

## 3. 部署独立微端服务器

1. 在微端服务器准备一份完整且可运行的客户端资源目录。
2. 将编辑器生成的微端网关 ZIP 复制到微端服务器并完整解压。
3. 启动网关 GUI，选择完整客户端目录，确认监听 IP、端口和项目 User。
4. 首次启动会扫描资源；健康状态显示就绪后再开放端口。
5. 如需长期运行，可由 GUI 注册 Windows Service，并按提示配置 URLACL 和防火墙。
6. 在路由器或云安全组中放行同一 TCP 端口；网关不会自动修改路由器或云控制台。

游戏服务器和微端服务器可以是两台机器。远程区服中的微端 IP 必须填写玩家实际可访问的地址，不能填写 `127.0.0.1`。

## 4. 生成并分发玩家入口

1. 在编辑器中选择“生成玩家 EXE”。微端启用时，编辑器会把同一项目的访问材料安全写入专属入口。
2. 生成成功后，可直接把单一 EXE 上传到网盘或群文件。
3. 玩家无需安装 .NET Desktop Runtime、SDK 或 VC++ 开发环境。
4. 玩家在已有兼容客户端目录运行时会复用该客户端；没有兼容客户端时，只需确认一次安装位置。
5. 启动核心完成后即可进入登录流程，其他资源在游戏中按需下载。

不要把编辑器项目的 `.secrets`、密钥恢复包密码或服务端受保护秘密发给玩家。

## 5. 发布主题、区服和公告更新

1. 在编辑器修改项目并执行发布前检查。
2. 发布到微端 `/launcher/`、普通静态 HTTP 目录，或导出离线部署包。
3. 所有版本必须由编辑器签名；玩家按“有效远程版本 → 上次有效版本 → EXE 内置版本”回退。
4. 普通入口更新失败时继续使用旧版；强制更新仅用于安全或兼容门槛。
5. 回滚不是降低序列，而是把历史内容以更高序列重新发布。

## 6. 日常维护

- 上传资源时先使用临时扩展名或独立上传目录，完成后再原子改名；网关会隔离未稳定文件。
- 修改完整资源后可在 GUI 执行“立即重扫”。
- 缓存损坏可以重建；清理缓存不会删除完整资源库。
- 更换服务器或重装系统前导出项目密钥恢复包，并把恢复密码单独保存。
- 网络配置撤销、服务卸载和恢复演练应在维护窗口操作。

## 7. 发布前最小检查

- 玩家 EXE 可在无辅助文件目录运行，重命名后仍可启动。
- 玩家机器不弹出安装 .NET Desktop Runtime 的提示。
- 游戏服地址、微端公网/局域网地址和端口均不是示例值。
- 微端四路由、Range、User/Code 和 Kill Switch 行为正常。
- 远程发布目录只包含签名发布工件，不指向完整客户端资源根。
- 保留上一可运行入口、项目恢复包和当前发布版本。

## 8. 当前验收边界

本机模拟、探针、自动化和 Windows 10 本机运维演练已经完成。Windows Server 2016 双机、真实网络 100 并发内存曲线、服务开机自启/多实例/事务强停及物理多档 DPI 仍需在目标环境留存证据；本次合并已获用户明确豁免这些项目为非阻断项，但不得对外宣称它们已经在实机执行。
