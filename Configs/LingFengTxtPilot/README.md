# 翎风 TXT 灰度候选

该目录是 TXT-14 的受控候选工件，不是线上运行数据目录。

- `Setup.fragment.ini`：合入目标服 `Setup.ini` 前必须逐项复核的配置片段；
- `Content`：只包含 1 个无经济副作用入口和登录、升级、NPC 代表性闭环；
- `snapshot.sha256`：候选内容逐文件摘要，路径统一使用 `/`；
- `rollback.fragment.ini`：一键关闭物理 TXT 并恢复 C# 优先的回退片段。

灰度顺序：先只开放 `NPCs/TXT灰度向导`，观察加载/分派/耗时；再启用 `SystemScripts/QManage` 与 `SystemScripts/QFunction-0`。TXT 登录页设置 `P0=1`，升级页设置 `P1=1`；NPC 验证当前地图、怪物计数并把会话变量 `P0` 改为 2，全程不修改金币、物品或其他经济资产。若目标服已有精确 C# 登录处理器，`CSharpFirst` 会按设计抑制 TXT 登录页；不能把 `P0=1` 当作该配置下必然发生的副作用。

候选配置每 60 秒把脚本指标原子导出到 `Logs/Scripts/runtime-metrics-latest.json`，用于对比平均值、最近 2,048 次调用的 P95/P99 和全期最大值。回滚片段会同时关闭该指标采集。

生产复制目标必须是独立受控内容根。禁止直接把本目录覆盖到数据库、日志、行会、地图或其他运行数据目录。脚本文件不会自动创建世界 NPC；部署者必须在数据库完整备份后单独建立唯一、可精确回滚的 NPC 定位记录。当前已验证候选使用 `npc_id=496`、`file_name=TXT灰度向导`，回滚时只能按这两个条件删除该记录。
