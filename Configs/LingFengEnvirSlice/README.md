# LFENV-16 单版本完整玩法候选

该候选从封神法宝语料的“法宝图鉴/首爆收录”规则抽取一条最小、可核账的完整切片：接受任务、在源版本“新龙城”地图击杀真实数据库中的“试炼守卫”、取得【法宝】乾坤圈、向 NPC 提交、获得【法宝】九龙神火罩与 200 金币。

源语料保持只读；候选仅使用当前已严格支持的 TXT 命令和共享 `NPCResponse`/`Chat` 协议。数据库必须存在两个同名物品和“试炼守卫”怪物，地图资源必须存在 `新龙城.map`；缺失时 E2 预检失败，不生成假数据。

上线按 `Setup.fragment.ini` 启用；回滚使用 `rollback.fragment.ini`，同时关闭物理 TXT、依赖门禁和 C#→TXT 回落。运行数据、账户、人物、地图、行会和日志不属于候选覆盖范围。
